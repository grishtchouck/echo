# Эхо

Игра в цепочку ассоциаций для компании в одной комнате, 3–12 игроков, у каждого свой телефон.

Каждый получает тайную легенду — известного человека или персонажа — и пишет к ней ассоциацию до 5 слов, не называя имени. Ассоциации уходят по кругу: каждый видит только последнюю и пишет свою. Раундов на один меньше, чем игроков (не больше 6), поэтому в финале у каждого цепочка, которую он ни разу не видел. Нужно угадать, с какой легенды она началась, из списка вдвое длиннее числа игроков. Потом все цепочки раскрываются целиком.

## Деплой на Vercel

1. Add New → Project → импортировать этот репозиторий. Framework Preset: **Other**, Build Command пустая.
2. В проекте: **Storage → Upstash for Redis** (план Free) → подключить к проекту. Vercel добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
3. **Redeploy**, чтобы функция увидела переменные.

## Устройство

- `index.html` — клиент, опрашивает сервер раз в 1,5 секунды.
- `api/echo.js` — Vercel Function. Состояние партии выводится из ответов игроков, поэтому одновременные ответы не конфликтуют. Комнаты живут 12 часов.
- `api/_echo-people.js` — список легенд, одна строка — одна личность.
- `art/` — иллюстрации.
